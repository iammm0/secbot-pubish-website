当前 `release` 分支通过 GitHub Release 发布用户安装产物，**不把 npmjs 公开发布当作主渠道**。版本线当前为 **0.0.7-beta**（桌面端、TUI 与 npm 线统一）。

## 1. 用户安装渠道

### 桌面安装包（Tauri）

`desktop-app-v*` GitHub Release 包含桌面安装包：

- macOS Apple Silicon：`.dmg`
- Windows x64：`.exe`（NSIS 安装包）
- Ubuntu / Linux x64：`.deb` 或 `.AppImage`

### TUI 自包含发行包

同一 Release 同时上传 `secbot-tui-<version>-<platform>` 自包含包（随包 Node 运行时 + 后端），解压后直接运行 `./secbot` 或 `secbot.cmd`，无需目标机安装 Node：

| 归档 | 平台 |
| --- | --- |
| `secbot-tui-<version>-macos-arm64.tar.gz` | macOS Apple Silicon |
| `secbot-tui-<version>-linux-x64.tar.gz` | Ubuntu x64 |
| `secbot-tui-<version>-windows-x64.zip` | Windows x64 |

> macOS Intel 不再支持。CI 还会把 `nuclei` / `ffuf` 等随包工具打进安装包与 TUI 包。

### npm 包

npm 包（`@opensec/secbot`）只发布到 **GitHub Packages**，不发布到 npmjs 公开渠道；预发布版本打 `beta` dist-tag。

## 2. 发布流水线

仓库根 `.github/workflows/` 提供多条流水线：

| 工作流 | 触发 | 产物 |
| --- | --- | --- |
| `desktop-release.yml` | tag `desktop-app-v*` 或手动 | 桌面安装包 + TUI 自包含发行包 |
| `release-pipeline.yml` | tag `rp-v*` 或手动 | npm 包（GitHub Packages）+ 桌面 + TUI |
| `release.yml` | tag `v*.*.*` | 仅 npm 包（GitHub Packages） |

桌面安装包与 TUI 发行包共用同一 `desktop-app-v*` 版本线；发布前检查以 `package.json`、release workflow 和验证脚本为准。

## 3. 本地发布前检查

```bash
npm ci
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
npm run build:terminal-ui
```

验证发布包：

```bash
npm run release:verify
```

打包：

```bash
npm run release:pack
```

或直接：

```bash
npm pack
```

## 4. package scripts

| 脚本 | 说明 |
|------|------|
| `npm run build` | 构建 NestJS 后端 |
| `npm run build:terminal-ui` | 构建 Ink TUI |
| `npm run build:web` | 构建 Web 前端（桌面端实际界面） |
| `npm run release:build` | 清理并构建后端 |
| `npm run release:pack` | 构建后端并执行 `npm pack` 生成 `.tgz` |
| `npm run release:verify` | 在临时目录安装 tarball 并验证二进制入口 |
| `npm run pack:tui` | 构建 TUI 自包含发行包 |
| `npm run fetch:tools` | 下载随包工具二进制 |

注意：根包的 `prepack` 会执行后端构建、TUI 构建、`web` 依赖安装和 Web 构建，因此直接 `npm pack` 也会生成完整产物。
