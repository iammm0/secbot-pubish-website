SecBot 配备了系统化、可严格复现的自动化安全评测套件，通过直连真实的工业级开源授权靶机环境（**DVWA `:8080`** 与 **OWASP Juice Shop `:3000`**），全面衡量模型在侦察、注入、文件包含、信息泄露、CVE 情报研判、复杂 DAG 任务规划以及安全红线把关（HITL）维度的自动化能力。

在最新的 `release` 分支评测中，SecBot 达成 **15 / 15 项任务 100.0% Pass@1**。

## 本地一键复现指南

SecBot 基准测试脚本完全开源，任何开发者均可在本地通过 Docker 极速拉起靶场并进行一键验证：

### 1. 启动靶场容器

```bash
# 进入 secbot 仓库目录，拉起 DVWA (:8080) 与 Juice Shop (:3000)
docker compose -f scripts/bench/docker-compose.yml up -d
```

### 2. 运行自动化基准评测

```bash
# 运行 15 项标准基准评测套件并输出 JSON 报告
npm run bench:standard

# 或者通过指定参数运行自定义任务集
node scripts/bench/run.mjs --tasks scripts/bench/tasks.standard.json --out scripts/bench/report.standard.json
```

## 核心设计与保障机制

1. **流式 SSE 与自动化人机协同（HITL）流**：
   - 基准运行器通过原生 `ReadableStream` 逐块解码 SSE 数据；
   - 当遇到敏感工具触发 `confirm_required` 或 `ask_user` 事件时，运行器能自动完成审批响应，全流程保留审计日志且无阻塞。
2. **连接生命周期级联保护**：
   - 服务端监听 `res.on('close')`，在客户端主动断开或超时时立即通过 `AbortController` 级联终止后台 LLM 与工具调用，杜绝孤儿进程泄漏。
3. **上下文预算感知**：
   - 评测中所有 Token 消耗直接绑定自后端的 `context_usage` 事件，精准量化大模型在多步规划决策下的实际成本效益。
