本节用于建立 SecBot 的稳定心智模型：它不是单一脚本集合，而是面向授权安全测试的 AI 工作台。当前主产品线是 v2 TypeScript，运行入口包括终端 UI、NestJS API 和 MCP server。

## 关于 runtime 命名

本站保留 `/docs/runtime` URL，但这里的 runtime 指 **SecBot 内部运行与执行链路**，不是独立仓库。它覆盖 Agent 编排、工具执行、Skills/MCP、记忆与扩展机制。
