## 执行链路

```mermaid
flowchart TD
  A["用户消息"] --> B["ChatService"]
  B --> C["IntentRouter"]
  C -->|needs_explore| D["ExploreAgent"]
  D --> E["ContextStore / ContextAssembler"]
  C --> F["SecurityReActAgent 或 PlannerAgent"]
  F --> G["TaskExecutor"]
  G --> H["ToolsService"]
  H --> I["安全工具 / MCP / Skills"]
  I --> J["SummaryAgent / Report"]
```
